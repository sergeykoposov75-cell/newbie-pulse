# Новичок: Пульс адаптации (Newbie Pulse)

## 🛠 Стек технологий
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- JSON (в качестве временной базы данных)
- KodaCode (AI-ассистент для написания кода)

## 🚀 Как запустить локально
1. Установите зависимости: `npm install`
2. Запустите dev-сервер: `npm run dev`
3. Откройте http://localhost:3000
4. Для сборки: `npm run build` и `npm run start`
